## Download Dreamforge {VERSION}

Pick the one line that matches your computer and click its file. You only download from this page once: after that, Dreamforge updates itself.

| Your computer | Click this file |
|---|---|
| **Windows PC** | [Dreamforge_{VERSION}_x64-setup.exe]({BASE}/Dreamforge_{VERSION}_x64-setup.exe) |
| **Mac with an Apple chip** (M1, M2, M3, M4 or newer; most Macs from late 2020 on) | [Dreamforge_{VERSION}_aarch64.dmg]({BASE}/Dreamforge_{VERSION}_aarch64.dmg) |
| **Mac with an Intel chip** (older Macs) | [Dreamforge_{VERSION}_x64.dmg]({BASE}/Dreamforge_{VERSION}_x64.dmg) |

**Not sure which Mac you have?** Click the Apple menu in the top-left corner, then **About This Mac**. If it says **Chip: Apple M1** (or M2, M3, M4), take the Apple chip file. If it says **Processor: Intel**, take the Intel file.

### Install on Windows

1. Open the downloaded file.
2. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**. This appears because the installer isn't signed with a paid Microsoft certificate.
3. Follow the installer, then open Dreamforge from the Start menu.

### Install on a Mac

1. Open the downloaded file and drag **Dreamforge** into **Applications**.
2. Open Dreamforge from Applications. The first time, macOS blocks it because it isn't notarized by Apple.
3. Open **System Settings**, then **Privacy & Security**, scroll down, and click **Open Anyway** next to Dreamforge. Confirm once more, and it opens normally from then on.

### You can ignore the other files

The files ending in `.app.tar.gz` and `.sig`, and `latest.json`, are what Dreamforge downloads by itself to update. The "Source code" links are added by GitHub. You don't need any of them.
